# TTGO T-Display Network Toolkit

Полевой сетевой тулкит на **LilyGO TTGO T-Display (ESP32)** — карманный комбайн для диагностики WiFi-сетей: сканер эфира, TCP-пинг с графиками, поиск живых хостов, анализ каналов и сканирование портов. Всё работает автономно от батареи.

## Возможности

| # | Экран | Что делает |
|---|-------|-----------|
| 1 | **WiFi Scanner** | Список сетей, отсортированный по силе сигнала: SSID, канал, RSSI, тип шифрования (OPEN/ENC) |
| 2 | **Ping Monitor** | Непрерывный TCP-пинг со сменой цели кнопкой (Google DNS / Cloudflare / шлюз), график задержки и статистика min/avg/max/loss |
| 3 | **Network Info** | IP, маска, шлюз, DNS, MAC, RSSI текущего подключения |
| 4 | **Host Scanner** | Ping-sweep всей подсети /24 (пробует порты 443 и 80), список живых хостов |
| 5 | **RSSI Walk** | Живой график уровня сигнала — ходишь по помещению и находишь мёртвые зоны WiFi |
| 6 | **Chan Analyzer** | Гистограмма загруженности каналов 1–13 + рекомендация самого свободного канала |
| 7 | **Port Scan** | Скан 18 популярных портов (21, 22, 80, 443, 445, 3389, 8080...) на шлюзе |
| 8 | **DNS Lookup** | Резолв имён из списка с временем отклика — проверка работоспособности DNS |
| 9 | **HTTP Test** | Реальный GET-запрос: HTTP-статус-код, размер ответа, время |

Плюс:
- **Индикатор батареи** в углу всех экранов (ADC GPIO34, делитель 1:2)
- **Часы с NTP-синхронизацией** в шапке меню
- **Автогашение подсветки** через 30 сек бездействия (экономия батареи), включение кнопкой
- **Автопереподключение к WiFi** после WiFi-скана (сканирование прерывает соединение)

## Управление

| Кнопка | Пин | Действие |
|--------|-----|----------|
| **BTN1** (верхняя) | GPIO0 | Листание меню / обновить / следующая цель |
| **BTN2** (нижняя, на обратной стороне платы) | GPIO35 | Выбор / назад в меню |

В Ping Monitor: **BTN1** циклически меняет цель пинга (8.8.8.8:443 → 1.1.1.1:443 → шлюз), сбрасывая статистику. В DNS Lookup: **BTN1** берёт следующее имя и резолвит его.

## Требования

**Железо:**
- LilyGO TTGO T-Display (ESP32, ST7789 240×135, две кнопки, батарейный разъём)

**Библиотеки (Arduino IDE → Library Manager):**
- [TFT_eSPI](https://github.com/Bodmer/TFT_eSPI) — Bodmer
- WiFi — встроена в ESP32 Arduino Core
- Сторонние библиотеки для пинга **не нужны**: «пинг» реализован через TCP-подключение (WiFiClient)

### Настройка TFT_eSPI (обязательно!)

1. В `User_Setup_Select.h` подключи пресет:
   ```cpp
   #include <User_Setups/Setup25_TTGO_T_Display.h>
   ```
2. Убедись, что в пресете включён пин подсветки `TFT_BL = 4` (скетч также включает её вручную на случай старых версий библиотеки).

## Установка

1. Установи [Arduino IDE](https://www.arduino.cc/en/software) и ESP32 core (Boards Manager → `esp32`).
2. Выбери плату: **ESP32 Dev Module**.
3. Настрой TFT_eSPI (см. выше).
4. Впиши свои данные в начало скетча:
   ```cpp
   const char* WIFI_SSID     = "Iphone";          // имя сети
   const char* WIFI_PASSWORD = "твой_пароль";      // пароль
   const long  GMT_OFFSET_SEC = 3 * 3600;          // часовой пояс (UTC+3)
   ```
5. Прошей, открой Serial Monitor (115200) — там виден статус подключения.

<details>
<summary><b>Если не подключается к точке доступа iPhone</b></summary>

ESP32 работает только на **2.4 ГГц**. В настройках точки доступа iPhone (Настройки → Режим модема):
- Включи **«Максимальная совместимость»** — иначе раздача идёт только на 5 ГГц;
- Держи экран телефона активным при подключении — iOS гасит раздачу при заблокированном экране;
- Проверь точное имя сети и пароль.

</details>

<details>
<summary><b>Диагностика статуса WiFi (Serial Monitor)</b></summary>

Коды `WiFi.status()` при загрузке: `3` = подключено, `1` = SSID не найден, `4` = неверный пароль, `6` = разорвано.

</details>

## Важные технические детали

### TCP-пинг вместо ICMP
ESP32 Arduino core не даёт удобного доступа к ICMP без сторонних библиотек, поэтому «пинг» здесь — время установления **TCP-соединения** на заданный порт. Это не настоящий ping:
- меряется время TCP-handshake, а не ICMP echo;
- хост без открытого порта будет считаться «мёртвым», даже если он жив.

Для роутеров/серверов обычно открыт порт 80 или 443. Цель по умолчанию — `8.8.8.8:443` (у Google DNS порт 80 закрыт). Смена цели — кнопкой, без перепрошивки.

### WiFi Scanner и подключение
Сканирование эфира на ESP32 требует отвлечения радиомодуля от подключения, поэтому сканер использует асинхронный `WiFi.scanNetworks(true)` и временно разрывает соединение. После возврата в меню тулкит автоматически переподключается — это занимает несколько секунд.

### Батарея
Напряжение измеряется через ADC на GPIO34 с делителем 1:2. Формула рассчитана на Li-Po 3.3–4.2 В. Если показания расходятся с реальностью — проверь пин и коэффициент делителя под свою ревизию платы.
